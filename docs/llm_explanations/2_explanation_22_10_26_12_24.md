# 2 — M1 slice 1: relatar → mapa, native-ready | 22/10/26 12:24

## What
Sessions (cookie or Bearer), insert-only masked relatos, privacy-safe map API, typed contract, and a mobile PWA (map, 3-step flow, outbox, share page).
🧠 policy and time parsing are stubs with 61 red tests; everything around them is built and verified.

## Why
Privacy leaks come from combinations, so they are tested as contracts: payload coordinates must be cell vertices, filters use display geometry, time windows are whole hours.
The frontend splits a static-exportable app zone from SSR share pages so TWA/Capacitor need no fork.
The API owns all writes, and one generated client serves web and a future app.

## Concepts
- **Fail closed**: on doubt, raise instead of serving (render_public on an exact view).
- **Mutation check**: break the code on purpose; a test that stays green is useless.
- **Static export zone**: code with no server-only features, so it can ship inside a native shell.
- **Contract drift test**: a committed OpenAPI copy whose staleness fails CI.
- **Outbox**: save locally first, send later; idempotent ids make retries safe.

## Assumptions
- Pilot timezone America/Sao_Paulo for parsing and labels; no free-text notes until moderation exists.
- Brazil bounding box rejects points outside the country.

## Watch out
- maplibre-gl.css sets position:relative on the map container; position a wrapper instead.
- TypeScript 7 removed the JS compiler API: generators run isolated with TS 6 (make api-contract).

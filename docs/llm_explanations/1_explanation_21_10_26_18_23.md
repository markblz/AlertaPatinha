# 1 — Repo foundation (M0) | 21/10/26 18:23

## What
Researched 7 tracks, then scaffolded Alerta Patinha Kubera-style: dockerized FastAPI + Next.js PWA + Postgres (PostGIS/h3/pgvector), Valkey, Centrifugo, SeaweedFS.
Wrote vision, glossary, architecture, data model, location privacy, roadmap, 10 ADRs; all gates and the live stack verified.

## Why
Value hinges on trust: wrong merges and location leaks hurt animals and people.
So identity is a human-confirmed hypothesis (relatos immutable, casos from append-only elos/blocos), and masking is server-side, write-time, stable.
Core logic is specified, not coded — the owner implements it first.

## Concepts
- **Bitemporal**: valid time (when seen) vs transaction time (when recorded).
- **Append-only log + projection**: state derived from events; cache is rebuildable.
- **Stable masking**: same input → same H3 cell; random noise averages out.
- **Transactional outbox**: enqueue side effects in the same DB transaction.
- **import-linter contracts**: architecture rules that fail the build.

## Assumptions
